# TaskFlow
 
A simple task management web application built by two developers as a Git and GitHub collaboration exercise.
 
## Features
 - Add, edit and delete tasks- Mark tasks as completed- Filter all, pending and completed tasks- Save tasks in the browser with localStorage
 
## Tech stack
 
HTML, CSS, JavaScript, Node.js, Vite, Jest, GitHub Actions and GitHub Pages.
 
## Run locally
 
```bash
npm install
npm run dev
```
 
## Tests and production build
 
```bash
npm test
npm run build
```
 
## Collaboration
 
Work is organized with Git branches, GitHub Issues, Pull Requests and code reviews.
